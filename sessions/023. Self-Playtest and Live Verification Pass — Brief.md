### Phase 2 — Confirm specific carried-forward fixes live

These have code and (mostly) test coverage but no live re-confirmation:

- Session 018's Restart and setup-base-cap UI fixes.
- Session 022's two incapacitation fixes: the Result screen's `incapacitatedSide` label, and
  the `State.setIncapableSince` fix for a player who recovers from an early Energy/Supply
  squeeze (previously stuck flagged forever; confirm a recovered player can no longer end the
  match on a stale incapacitation).
- Session 022's Energy-allocation fix's real tradeoff — a cheap weapon (cannon) now holds
  fire whenever a costlier one (mortar/missile) is also eligible, which the session confirmed
  numerically but only in an adversarial two-weapon scenario. Play a few ordinary matches and
  confirm this doesn't make the cheap weapon feel dead weight in practice.

### Phase 3 — Fresh sweep

Run `lune run sweep` fresh — today's tuned `config.luau` values still come from Session 019's
sweep, predating Session 020's archetype changes. Compare against the current shortlist; only
apply a change here if something is clearly broken the way Session 019 found `CANNON_RANGE`/
`ENERGY_PER_GENERATOR_PER_SECOND` broken, not a general retune (that's still its own future
balance session per the existing "Ship polish and balance pass" precedent).
