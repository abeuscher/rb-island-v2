# Session 004 — Board in Studio — Brief

**Type:** feature
**Shape:** plan-backed
**Branch:** session-004

## Goal

Sync a full-size board with the channel and both starting islands into Studio via Rojo,
render elevation as clearly distinguishable stacked-cube levels, and add a scriptable
camera that frames each player's own territory. No avatars are spawned.
