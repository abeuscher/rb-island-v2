# Session 003 — Simulation Harness and First Balance Sweep — Brief

**Type:** feature
**Shape:** plan-backed
**Branch:** session-003

## Goal

Build the headless simulation harness and run the first balance sweep: five scripted
archetype strategies playing round-robin matches through the now-complete rules core,
producing per-match logs, an aggregate CSV, and the core balance metrics from §15.

## Starting state

- `src/shared/` is feature-complete for a headless match: `rules.resolveRound` runs a full
  round including combat, fog, income, and victory, driven entirely by per-player command
  batches. 51 Lune tests pass.
- No archetype, harness, or scripted-strategy code exists yet — this session is the first
  to write anything under `/sim`.
- **Hard requirement carried from §15:** an archetype's decisions must read only its own
  `belief` map (plus public terrain), never the opponent's true structure state. The
  harness needs to enforce or at least verify this, since an archetype that peeks
  invalidates the whole sweep.
- The housekeeping inbox is empty; nothing to absorb this session.

## Out of scope

Rojo/Studio rendering and everything client/server — later plan entries. Balance
perfection — this session narrows to a shortlist for human playtesting, it doesn't decide
final numbers.
