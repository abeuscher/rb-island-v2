# Session 015 — Bot Re-adaptation — Brief

**Type:** feature
**Shape:** plan-backed
**Branch:** session-015

## Goal

Bring `server/Bot.luau` back to a playable state under the real-time tick loop — periodic
re-decide instead of one `decide()` call per old PLAN phase — so a player can play against the
bot again, on all three difficulty presets, under the same real-time cooldown/economy rules a
real player is held to.
