# Session 006 — Resolve Phase vs. Dummy Opponent — Brief

**Type:** feature
**Shape:** plan-backed
**Branch:** session-006

## Goal

Build the RESOLVE phase against a static dummy enemy layout: aiming and firing a volley
animates both sides' shots firing simultaneously, direct fire visibly stops at ridges,
damage/rubble apply, and the belief map updates to show exactly what was revealed.

## Starting state

- The plan-phase UI (build/bulldoze, terrain edit/reclaim, targeting, round clock) is done
  and local-only — see Session 005's log for the local `MatchState`/`PlanController` shape.
- Targeting only validates that a target cell is on the enemy island; range and
  line-of-flight blocking were explicitly deferred to this session, since they need
  `flight.luau`.
- There is no dummy enemy layout yet — this session needs one (a static, hardcoded
  structure layout on the "B" side, per the plan entry's own scope) to have something to
  shoot at.
- `PlanController:advanceRound()` currently only runs `completeConstruction` and
  `accrueIncome` — no volley resolution. This session is where `rules.luau`'s resolve step
  (or the relevant pieces of it) gets wired in for the first time.
- The housekeeping inbox is empty; nothing to absorb this session.
