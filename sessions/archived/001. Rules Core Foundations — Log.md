# Session 001 — Rules Core Foundations — Log

**Date:** 2026-09-17
**Branch:** session-001
**Type:** feature

## What was built

### Phase 1 — Rojo and Lune scaffolding

- Wired up `rokit.toml` pinning Lune 0.10.5 and Rojo 7.7.0, since neither was installed for
  this project yet.
- Added `default.project.json` mapping `src/shared` to `ReplicatedStorage/Shared`; server and
  client trees are left out until sessions that add those directories need them.
- Built a minimal Lune test runner: `tests/testkit.luau` (assert-style `test`/`expectEqual`/
  `expectTrue`/`expectFalse`/`summary`) and `.lune/test.luau`, which discovers and requires
  every `tests/*.spec.luau` file and reports a pass/fail summary. `lune run test` now works
  end to end.

### Phase 2 — Rules core modules (`src/shared/`)

- `config.luau` — every tuning constant from §§3, 7, 8, 9: board/channel/island dimensions,
  elevation bounds, terrain edit and reclamation costs, Supply/Energy constants, unlock
  rounds, and the full structure roster (base, generator, cannon, mortar) per the §8 schema.
- `board.luau` — grid, territory split around the channel, starting 12×12 islands flush
  against the channel and centered vertically, elevation with the smoothness constraint,
  and pure `raise`/`lower`/`reclaim` operations. Copy-on-write: only the touched column is
  rebuilt per edit.
- `economy.luau` — Supply/Energy accrual (`accrue`) and spend (`spend`/`canAfford`).
- `structures.luau` — footprint-aware placement/bulldoze/build-completion on top of the
  roster in `config.STRUCTURES`, with occupancy and territory checks.
- `state.luau` — `MatchState` shape and initializer, plus the command-level operations
  (`placeStructure`, `bulldozeStructure`, `raiseTerrain`, `lowerTerrain`, `reclaimLand`,
  `completeConstruction`, `accrueIncome`) that compose the three modules above with unlock
  gating and affordability checks. Full round-sequencing across simultaneous two-player
  commands stays out of scope — that's `rules.luau`, next session.
- 30 Lune tests across four spec files cover territory/elevation/smoothness, economy
  accrual/spend, structure placement/bulldoze/build-time, and the composed state operations.

### Phase 3 — Decisions logged

Created `DECISIONS.md` (referenced by the repo layout but not yet created) and logged three
ambiguity calls made along the way:

- Players open round 1 with one round's Supply already banked, mirroring `STARTING_ENERGY`.
- The §3 smoothness constraint also applies to land reclamation, not just terrain edits.
- The §8 rule blocking structure placement on a cell being terrain-edited the same round
  needs whole-round command-batch awareness this session's per-action functions don't have;
  deferred to next session's `rules.luau`.
