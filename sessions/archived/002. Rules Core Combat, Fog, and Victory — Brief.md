# Session 002 — Rules Core Combat, Fog, and Victory — Brief

**Type:** feature
**Shape:** plan-backed
**Branch:** session-002

## Goal

Complete the pure, headless rules engine: line-of-flight (direct and arcing fire),
simultaneous volley resolution, fog reveals with stale belief maps, round-based unlock gates
wired into a real round loop, and all four victory conditions — including simultaneous mutual
base elimination. By the end, a full scripted match runs end to end in the terminal with a
green test suite.

## Starting state

- `src/shared/` has `config.luau`, `board.luau`, `economy.luau`, `structures.luau`, and
  `state.luau` — all pure, all covered by Lune tests (30 passing). `lune run test` is wired as
  this project's `test-command`.
- `state.luau` has no round-advancement function yet — this session is the first to need one,
  as part of `rules.resolveRound`.
- Three decisions from Session 001 apply here: opening Supply equals one round's income,
  reclamation is smoothness-checked like terrain edits, and the §8 same-round
  terrain-edit/placement interaction (structures can't be placed on a cell being terrain-
  edited the same round) is this session's to implement, since it needs whole-round
  command-batch validation that didn't exist before now.
- The housekeeping inbox is empty; nothing to absorb this session.
