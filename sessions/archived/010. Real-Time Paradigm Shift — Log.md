### Phase 3 — Plan.md entries drafted

Replaced the "Real-time combat and economy (paradigm shift)" placeholder entry with five
sequenced entries:

1. **Real-time rules core** — tick-based cooldown combat, rate-based economy, `readyAt`
   construction, continuous victory checks, match clock replacing `MAX_ROUNDS`.
2. **MatchService real-time loop** — phase machine collapses to setup → one live phase →
   result; drops the immediate-apply/replay two-track command model entirely.
3. **Bot re-adaptation** — periodic re-decide cadence, time-keyed staleness tracking.
4. **Client real-time UI** — match clock with no round counter, per-weapon cooldown
   indicators, continuous economy display, event-driven shot animation, base tool
   pre-selected by default in setup.
5. **Sim harness rewrite** — discrete time-step stepping, every round-keyed metric
   re-derived.

"Ship polish and balance pass" kept as a single entry (not split — the sim-harness port and
the balance sweep it enables are sequential steps of one effort, not independently useful
halves), with its prerequisites updated to point at the four entries above it actually
depends on.
